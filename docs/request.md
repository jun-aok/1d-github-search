## 依頼内容

GitHub のリポジトリを検索する Web アプリケーションを Next.js で作成する。

## 指定環境

- Next.js v16 以降
- App Router を使用する
- 使いたいコンポーネントライブラリ（shadcn/ui 等）があれば、任意で使用してよい

## 最低動作要件

1. 何かしらのキーワードを入力する
2. GitHub API (`search/repositories`) でリポジトリを検索し、検索結果を一覧表示する
3. 特定の結果を選択したら、該当リポジトリの詳細（リポジトリ名、オーナーアイコン、プロジェクト言語、Star 数、Watcher 数、Fork 数、Issue 数）を表示する
4. 詳細画面はモーダルではなくページとして実装する
5. テストコードを記述する

## 心がけてほしいこと

- プロダクションを想定した実装にする
- ワイヤーフレームはあくまでも参考であり、必ずしもその通りの見た目に実装する必要はない
- デザイン性は評価軸ではないが、見やすさや操作しやすさは意識する
- ページネーションや無限スクロールへの配慮を行う（ワイヤーフレームの注記）

## ワイヤーフレーム

![ワイヤーフレーム](https://img.esa.io/uploads/production/attachments/17090/2025/02/21/145195/182998f5-0bf1-49db-b6bd-8cc2128371d5.png)

読み取れること:

- 検索ページ: タイトル、入力欄（「リポジトリ名を入力してください」）と検索ボタン、結果の一覧（各行はオーナーアイコン + リポジトリ名）
- 詳細ページ: タイトル、オーナーアイコン、リポジトリ名、言語、Star 数 / Watcher 数 / Fork 数 / Issue 数
- 一覧の行を選ぶと詳細ページへ。詳細ページのタイトルからトップページへ戻る
